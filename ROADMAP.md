# Divmora Website Living Roadmap

This living roadmap outlines planned capabilities, optimizations, and features for the official Divmora Technologies web portal.

---

## 🚀 Active Backlog

### Core Enhancements
- [ ] **Interactive Playground**: Embed live WebAssembly or browser terminal demonstrations of tools like `lhctl` and `owlflow`.
- [ ] **Technical Blog & Case Studies**: Markdown-powered engineering blog engine covering architecture deep-dives and release highlights.
- [ ] **Dark / Light Theme Toggle**: Seamless system-aware theme switcher with persistent user preference storage.
- [ ] **Search & Filter Modal**: Full-text fuzzy search across all repositories, tags, and architectural categories (`⌘K` command palette).

### Performance & SEO
- [ ] **OpenGraph Dynamic Social Cards**: Automated generation of OG preview cards for GitHub releases and project shares.
- [ ] **Lighthouse 100/100 Audit**: Image format optimization (WebP/AVIF) and critical CSS inline delivery.
- [ ] **RSS Feed Generation**: Continuous RSS XML feed generation on build for engineering release updates.

---

## 📋 Lifecycle Protocols

- **Adding Items**: When a new feature or architectural idea is identified, add it to this roadmap under the appropriate category.
- **Removing Items**: When a roadmap task is implemented, verified, and committed to `main`, remove it from this file.
