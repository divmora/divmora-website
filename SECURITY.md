# Security Policy

At **DIVMORA Technologies**, we take security and vulnerability disclosure seriously.

---

## 🛡️ Supported Versions

We actively maintain and provide security updates for the current production deployment of the website:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| `< 1.0` | :x:                |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability, we ask that you report it privately and responsibly:

1. **Email Privately**: Send full details of the vulnerability to [security@divmora.com](mailto:security@divmora.com).
2. **GitHub Security Advisories**: Alternatively, you can use the [Private Vulnerability Reporting](https://github.com/divmora/divmora-website/security/advisories/new) tool directly on this repository.
3. **Response SLA**: Our engineering team will acknowledge your report within **48 hours** and provide regular status updates until a resolution is deployed.

Please **do not** open public issues or pull requests detailing security vulnerabilities before they have been addressed.
